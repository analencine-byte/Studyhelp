# Studyhelp# StudyHelp

O **StudyHelp** é uma plataforma criada para facilitar o aprendizado e incentivar a colaboração entre estudantes e professores. O sistema busca tornar a educação mais acessível, organizada e colaborativa, oferecendo um espaço para compartilhar materiais, organizar conteúdos e interagir com outros usuários.

## Objetivo

O projeto foi desenvolvido com o objetivo de auxiliar estudantes em seus estudos e permitir que professores compartilhem materiais e conteúdos educacionais de forma organizada.

## Funcionalidades

* Acesso a materiais de estudo;
* Criação e organização de anotações;
* Chat ou fórum para interação entre estudantes e professores;
* Compartilhamento de arquivos e vídeos;
* Busca por conteúdos;
* Sistema de cadastro e login;
* Controle de acesso de acordo com o tipo de usuário;
* Recuperação e exclusão de conta.

## Tipos de usuários

O sistema possui diferentes níveis de acesso:

### Visitante

Pode visualizar conteúdos disponíveis, porém possui acesso limitado a determinadas funcionalidades.

### Estudante

Pode acessar materiais de estudo, utilizar os cadernos para anotações e participar das interações disponíveis na plataforma.

### Professor

Pode cadastrar matérias, publicar, editar e organizar materiais de estudo para os estudantes.

### Administrador

Responsável pelo gerenciamento do sistema e dos usuários, incluindo a aprovação e definição de professores.

## Sobre o projeto

O StudyHelp foi desenvolvido como um projeto acadêmico para a disciplina de **Programação para Internet II**. O sistema utiliza conceitos de desenvolvimento web, banco de dados, autenticação de usuários e controle de permissões.
